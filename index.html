Pipeline

  1. Collect: CRM CSV, SQL billing database (40,000 transactions), support tickets (9,000)
  2. Clean: removed 60 duplicates, fixed 25 invalid ages, filled 80 missing regions
  3. Integrate: SQL aggregation plus Pandas joins into one 5,000-customer dataset
  4. Validate: 8 automated data-quality checks
  5. Analyse: t-test, ANOVA, chi-square, correlation
  6. Model: Logistic Regression and Random Forest, train/test split and 5-fold CV

Recommendation

Prioritise faster ticket resolution and outreach to low-CSAT customers, rather than plan- or region-based campaigns. Customers with slower-than-median resolution churned at 48.0% versus 28.2% for faster ones.

Limitations

  • Moderate AUC; model is used to rank drivers, not predict precisely
  • Synthetic data
